# Adding a language

A language is a folder of data. No code changes, no rebuild of anything but
the resources.

```
HomeRow/Resources/Languages/<id>/
    info.plist        required
    words-200.txt     at least one words-*.txt is required
    words-1k.txt
    LICENSE           required: where the words came from, and their licence
```

`<id>` is the language's name in lowercase English (`english`, `german`,
`norwegian_bokmal` — MonkeyType's names, since most packs come from there)
and must equal the `identifier` in `info.plist`.

To try a pack without rebuilding, put the folder in
`~/Library/Application Support/HomeRow/Languages/` on macOS, or
`~/GNUstep/Library/ApplicationSupport/HomeRow/Languages/` on GNUstep. A pack
there with the same identifier as a bundled one replaces it.

## info.plist

| Key | Required | Meaning |
|---|---|---|
| `identifier` | yes | same as the folder name |
| `displayName` | yes | the language's name in the language itself |
| `alphabet` | yes | every character the word lists use, as one string. It is read as a set of code points, so combining marks are listed on their own; uppercase forms are implied |
| `bcp47` | no | language tag, e.g. `de-DE` |
| `defaultLayout` | no | layout pack to preselect; default `qwerty-us` |
| `script` | no | ISO 15924 code, e.g. `Latn`, `Cyrl` |
| `direction` | no | `ltr` (default). `rtl` is reserved and not supported yet |

See `english/info.plist` for a complete example.

**Keep `info.plist` ASCII.** Write non-ASCII characters as XML character
references (`&#xE9;` for é). gnustep-base currently reads raw UTF-8 inside an
XML property list as Latin-1, so `é` would arrive as two characters;
references come through intact on both platforms. `Scripts/import-monkeytype.py`
does this for the packs it writes. The word lists themselves are plain UTF-8.

## Word lists

UTF-8, one word per line, most frequent first. Blank lines and lines
starting with `#` are ignored. No duplicates. Every character must be in
`alphabet` (apostrophes are allowed). Name lists by size: `words-200`,
`words-1k`, `words-5k`, `words-10k`.

## Licensing

HomeRow is GPL-3.0-or-later and everything it ships has to be compatible
with that: GPL (2-or-later, 3), LGPL, MIT/BSD, CC0, CC-BY, public domain.
Not CC-BY-NC or -ND, and not lists copied from proprietary typing sites. Say
where the words came from, and under what licence, in `LICENSE`.

Packs that came from MonkeyType are regenerated by the import script — fix
those upstream, or the next import will undo the fix.

## Checking your pack

`make check` (or the Xcode test action) runs `HRLanguageTests`, which loads
every bundled pack and fails on a missing key, an empty or duplicated list,
or a character outside the alphabet. CI runs the same test, so a broken
pack cannot be merged.

## Courses

Courses are GNU Typist `.typ` scripts in `HomeRow/Resources/Lessons/gtypist/`,
listed in `index.plist` there with a title, the language pack they belong to
and the layout they teach. The format is described in the GNU Typist manual
("Script file commands") and at the top of `HomeRow/Engine/HRTypScript.h`.
A new course is a `.typ` file plus an `index.plist` entry; `HRTypScriptTests`
parses every course and fails on a broken one.

Keyboard-layout packs come with v0.2; see `docs/feature-set.md`, section 7a.
